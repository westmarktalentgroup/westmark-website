# Westmark Talent Group Website

Static website for Westmark Talent Group, hosted on GitHub Pages at
https://www.westmarktalentgroup.com

## Structure

- `index.html` — home page (hero, mission, opportunities, FAQ)
- `clients.html` — process and services for employers
- `contact-us.html` — contact information
- `logo.html` — logo download page (not indexed)
- `assets/css/optimized.css` — all styles
- `assets/js/consolidated.js` — navigation, FAQ accordion, forms
- `assets/images/` — images (WebP with JPG/PNG fallbacks)
- `sw.js` — kill-switch that removes the old service worker from visitors' browsers

## Editing

Edit the HTML/CSS files directly and push to `main` — GitHub Pages deploys
automatically. Job listings are in the "Current Opportunities" section of
`index.html`; each card links to the Zoho Recruit posting.
